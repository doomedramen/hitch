hitch::operations

Module model 

Source
Expand description

The types a plan is made of, and the types a receipt is made of.

See the super module header for why a plan is a decision rather than a recipe. This file is deliberately declarative: it holds the vocabulary every operation shares, and the planners in sibling modules decide what fills it in.
