Land a completed rebase: move refs/heads/<branch> to the rebased tip with a compare-and-swap, bring any checkout standing on it back in line, and offer the force push. Shared by the clean-first-try path and --continue.

retry_hint is the command to suggest if the publish CAS loses a race — the caller decides it because the right retry differs by call site: resolve_mode_a’s first-try path has no resumable session (cleanup runs unconditionally after this call), so its hint must start fresh with no --continue; continue_rebase_session preserves the session worktree on failure, so --continue is genuinely resumable there.
