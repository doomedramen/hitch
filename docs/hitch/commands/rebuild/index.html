run
Runs the rebuild. Returns Ok(true) if it succeeded but held one or more conflicting branches (or, under --dry-run, would have) — the caller uses this to choose a distinct “succeeded with holds” exit code (2) instead of the plain-success 0, so CI can warn without failing the build. Ok(false) is a fully clean success; Err covers both a halt-policy refusal and any other failure (both exit 1, matching prior behavior).
