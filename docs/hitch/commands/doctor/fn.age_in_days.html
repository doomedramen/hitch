fn age_in_days(recorded_at: &str, now: DateTime<Utc>) -> Option<i64>

Age in whole days of an RFC3339 timestamp relative to now, or None if it doesn’t parse (a malformed timestamp is treated as “unknown age”, never as stale, so a parse quirk can’t trip the CI gate).
