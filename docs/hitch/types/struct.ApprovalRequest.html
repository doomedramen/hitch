Current status of request

List of approvals received

§rejection: Option<Rejection>

Rejection details (if rejected)

§rebuild_snapshot: RebuildSnapshot

Snapshot of branch states at request time

§snapshot_min_approvals: Option<usize>

The approval threshold frozen at request-creation time. Evaluating the threshold against this (rather than the environment’s live min_approvals) prevents a later hitch set --min-approvals from retroactively satisfying or invalidating an in-flight request. None for requests created before this field existed, in which case the environment’s current value is used.

pub fn required_approvals(&self, environment: &Environment) -> usize

The approval threshold governing this request.

Uses the value frozen at creation time when present, falling back to the environment’s current min_approvals for older requests. This is what keeps threshold evaluation stable across hitch set --min-approvals.
