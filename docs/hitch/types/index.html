SUPPORTED_CONFIG_MAJOR
The maximum config schema MAJOR version this binary knows how to safely rewrite. Reading a newer config is tolerated, but rewriting one is refused (see HitchConfig::check_write_compatibility) because serde silently drops fields this binary doesn’t model, which would corrupt a newer config on save.
