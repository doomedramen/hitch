Expand description

Read an environment’s build record and classify it against the branch’s current tip.

Returns Err only for genuine I/O failure — a git invocation that itself failed. A record that is missing, unparseable, ahead of this hitch’s schema, or inconsistent with the branch is a state, returned as a value, because the alternative is a hitch status that cannot render a repo containing one bad blob.
