Local-only variant of preflight_compatibility_report, for callers like hitch status/hitch tree that display per-branch state on every invocation and must stay fast and offline — unlike rebuild --dry-run and hitch conflicts, this never fetches. It works only from whatever is already resolvable locally (existing local branches or remote-tracking refs); a branch that isn’t resolvable is silently skipped rather than erroring, matching the .unwrap_or(false) best-effort style the rest of hitch status’s per-branch checks already use — that branch’s other state (missing, stale, etc.) is what should explain it to the user, not this function.
