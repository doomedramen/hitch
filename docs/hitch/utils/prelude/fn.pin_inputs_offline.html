Resolve an environment’s inputs from local refs alone, the way build_state_snapshot does: refs/heads/<b>, then the cached refs/remotes/origin/<b>, and nothing else. No ls-remote, no fetch.

A promoted branch that resolves nowhere is dropped from the pins rather than failing, which is what the tree-based local preflight it replaced did (continue): that branch’s own state (missing, stale) is what should explain it, not a prediction. An unresolvable base is an Err, because a composition needs a starting commit; display callers go through predict_composition_if_base_resolves, which turns only that case into “no prediction”.
