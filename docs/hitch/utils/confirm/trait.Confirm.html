Expand description

Abstraction over “ask the user to confirm a destructive action”.

Every interactive prompt in Hitch goes through this trait so that a single global --yes (or a non-interactive session) is handled in one place instead of each command re-implementing a read_line loop.

fn confirm(&self, prompt: &str) -> Result<bool>

Ask prompt and return whether the user agreed.

Implementations must never block forever: when there is no terminal to read from they return an error telling the caller to pass --yes.
