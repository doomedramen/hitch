Write a document to stdout, pretty-printed, followed by exactly one newline.

The explicit flush is load-bearing for the same reason main.rs’s is before process::exit(2): process::exit skips normal shutdown, so a rebuild that exits 2 with branches held would otherwise lose the very document that explains why. A CI job that cannot read the JSON is the failure this flag exists to prevent.

to_string_pretty over to_string because the document is read by humans in a terminal about as often as by programs, and a single-line plan object is not reviewable in a CI log.
