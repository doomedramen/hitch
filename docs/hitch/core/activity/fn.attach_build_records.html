Fills in the outcome of the newest Rebuilt event per environment, and only when the live build record provably came from that rebuild. The record’s metadata_sha is a transient tip written after the rebuild’s lock commit and before its rebuilt_at stamp (c1), so it must be c1 or an ancestor on the first-parent line, and no commit strictly between the two may have stamped rebuilt_at again (that would be a later rebuild that wrote no record). The range check reads history beyond the walk, so a truncated walk still attaches. Any doubt (unreadable commit, non-Known record, a metadata_sha off the first-parent line) leaves the event Unrecorded; a wrong attachment is worse than none.
